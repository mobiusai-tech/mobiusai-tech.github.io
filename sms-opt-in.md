<h1>SMS opt-in for Mobi Motion sign-in codes</h1>

<p>This page documents how a user consents to receive text messages from Mobius.AI, Inc., and what those messages contain.</p>

<h2>Who sends these messages</h2>

<ul>
  <li><strong>Business:</strong> Mobius.AI, Inc.</li>
  <li><strong>Product:</strong> Mobi Motion — demand-responsive public transit software used by transit agencies and their riders and drivers</li>
  <li><strong>Support:</strong> <a href="mailto:Inquiries@mobiusai.tech">Inquiries@mobiusai.tech</a></li>
  <li><strong>Website:</strong> <a href="https://www.mobiusai.tech/">www.mobiusai.tech</a></li>
</ul>

<h2>What we send</h2>

<p>One message type only: <strong>a one-time sign-in code</strong>, sent when the user asks for it. We do not send marketing, promotional, or advertising content to this number, and the sign-in code is never bundled with other content.</p>

<p>The message reads exactly:</p>

<blockquote style="border-left: 3px solid #ccc; margin: 16px 0; padding: 8px 16px; background: #f7f7f7;">
Your Mobi Motion sign-in code is 123456. It expires in 5 minutes.
</blockquote>

<h2>How a user opts in</h2>

<p>Consent is given by the user entering their own mobile number and asking for a code. There is no pre-checked box and no way to receive a message without taking this action.</p>

<ol>
  <li>The user opens the Mobi Motion app and reaches the sign-in screen.</li>
  <li>The screen states that we will text a sign-in code, discloses that standard message and data rates may apply, and links to our Terms and Privacy Policy.</li>
  <li>The user types their own mobile number and taps <strong>Continue</strong>. This action is the opt-in.</li>
  <li>We send one sign-in code to that number.</li>
  <li>The user enters the code to complete sign-in.</li>
</ol>

<p>No message is ever sent to a number that has not been typed into this screen by the person holding the handset.</p>
